# ☁️ CloudSphere 360

### Interactive Salesforce Cloud Architecture Learning Hub

**CloudSphere 360** is an interactive learning application built with Salesforce Lightning Web Components (LWC), JavaScript, HTML, and CSS.

The project demonstrates cloud computing fundamentals through interactive topics, real Salesforce examples, and a dynamic learning progress tracker.

## Features

- **Interactive Learning Cards:** Explore six essential cloud computing topics.
- **Dynamic Content:** Display explanations and Salesforce use cases when selecting a topic.
- **Learning Progress Tracker:** Track completed topics with a real-time progress bar.
- **Responsive Design:** Adapt the dashboard layout to different screen sizes.
- **Reset Functionality:** Restart the learning experience at any time.

## Topics Covered

1. Cloud Architecture — SaaS, PaaS, and IaaS
2. Cloud Security — Access Control and Data Protection
3. Data Cloud — Data Integration and Unification
4. Cloud Integration — APIs and Connectivity
5. Cloud Monitoring — Logs and Performance
6. Cloud Deployment — DevOps and CI/CD

## Architecture

The current application uses a client-side LWC architecture:

**Salesforce Lightning App Page → LWC Component → JavaScript State Management → Interactive UI**

The dashboard dynamically updates the selected topic and learning progress without requiring a page reload.

## Salesforce Implementation

The application was developed in Visual Studio Code, deployed to a Salesforce Developer Edition org, and integrated into a Salesforce Lightning App Page using Lightning App Builder.
